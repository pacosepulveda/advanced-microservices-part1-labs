# P07 — Extensiones
- Diseña un proceso de reconciliación de discrepancias históricas con auditoría, idempotencia y aprobación; no ejecutarlo sobre datos reales.
- Diseña una prueba de fallo HTTP y resultado incierto, con recuperación tras respuesta perdida; no asumir rollback global.
- Propón métricas de negocio y alertas: pedidos cancelados con reservas activas, antigüedad de transiciones y retraso de proyección.
- Analiza cómo se modifica la solución con múltiples orquestadores concurrentes y un Outbox.
