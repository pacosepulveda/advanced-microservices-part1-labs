# P05 — Extensiones
- Diseña autenticación del webhook con timestamp, ventana de replay, rotación y deduplicación persistente; HMAC por sí solo no evita reenvíos legítimos o maliciosos.
- Diseña evolución de Protobuf con campos nuevos y números reservados; no renumerar ni reutilizar tags eliminados.
- Propón mTLS para gRPC, propagación de deadline y cancelación cooperativa; explica qué se debe comprobar en producción.
- Compara RPC unary, streaming y REST para una cotización frente a una secuencia de actualizaciones. No implementar integraciones reales.
