## Código y recuperación de sesiones

- **Cada checkpoint resuelve las prácticas anteriores** e incluye el código de arranque de la práctica actual. Conserva tu trabajo en una rama propia y sigue las instrucciones de la guía general del alumno antes de actualizar tu fork.
- Si no asististe a una sesión, consulta el enunciado, recupera el checkpoint siguiente (cuando se haya publicado) y examina el código completado en `services/`. Los cambios no se publican por adelantado.
- Tras finalizar P07, el instructor facilitará la referencia de solución final, pues no existe un P08 que la incorpore automáticamente.
- No utilices soluciones de ejercicios posteriores antes del trabajo en clase. Los enlaces a rutas de código todavía inexistentes pasan a estar disponibles cuando se publica su checkpoint.

Para empezar, consulta la [guía general de trabajo](../../labs/GUIA-ALUMNO.md).
